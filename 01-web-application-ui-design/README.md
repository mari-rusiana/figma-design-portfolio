# Web Application UI Design

## Project Overview

This project involved creating interface design proposals for the Home and About pages of a web application using Figma.

Several concepts were developed to explore different layouts, visual arrangements, and information structures. The selected concepts were then refined into the final designs.

## My Role

I was responsible for creating and refining the interface designs in Figma.

My work included:

- Creating eight Home page design proposals
- Creating three About page design proposals
- Exploring different page structures and visual directions
- Organizing content into clear sections
- Establishing information hierarchy
- Refining designs based on requirements and feedback
- Developing the final selected Home and About page designs
- Maintaining visual consistency between related screens
