# Scrollable Overlay Figma Tutorial

## Project Overview

This client tutorial project demonstrates how to design and configure a scrollable overlay in Figma.

The tutorial shows how overlay content can be displayed within an interface while allowing the user to scroll through additional information.

## My Responsibilities

- Created the overlay interface design in Figma
- Configured the scrollable content behavior
- Set up the overlay and prototype interactions
- Prepared the completed design preview
- Captured the prototype flow for documentation
- Structured the tutorial content for clear visual understanding
