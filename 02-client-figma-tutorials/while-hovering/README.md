# While Hovering Figma Tutorial

## Project Overview

This client tutorial project demonstrates how to create a hover interaction in Figma.

The tutorial shows how an interface element can change its appearance or state when a user hovers over it, using Figma's interactive components and prototyping features.

## My Responsibilities

- Created the interface design in Figma
- Developed the hover state and interaction
- Configured component variants and prototype behavior
- Prepared the final design preview
- Captured the prototype flow for documentation
